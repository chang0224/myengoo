### ¶14

개인 기여자로서는 / 당신의 영어가 / 아닐 수도 있다 / 그렇게 중요하지. / 하지만 일단 당신이 되면 / 매니저가 / 당신은 전달해야 한다 / 피드백을. /

The words and expressions / you choose / become very important. / I paid attention / to how good managers spoke / in meetings / and gave feedback. /
단어와 표현들은 / 당신이 선택하는 / 매우 중요해진다. / 나는 주의를 기울였다 / 좋은 매니저들이 어떻게 말하는지에 / 회의에서 / 그리고 피드백을 주는지에. /

I also read / business leadership books, / especially Crucial Conversations / and Crucial Confrontations. / They taught me / useful expressions, / so I wrote them down, / memorized them, / and rehearsed them / before giving feedback.

### ¶15

In America, / especially in Silicon Valley, / many people have / big dreams / and are not shy / about expressing / what they want. /
미국에서는 / 특히 실리콘밸리에서는 / 많은 사람들이 가지고 있다 / 큰 꿈들을 / 그리고 부끄러워하지 않는다 / 표현하는 것에 대해 / 그들이 원하는 것을. /

Korean people, / in general, / do not act like that. / If you want / to be successful / and recognized here, / you have to talk about / your ambition / and dream. /
한국 사람들은 / 일반적으로 / 그렇게 행동하지 않는다. / 당신이 원한다면 / 성공하기를 / 그리고 여기서 인정받기를 / 당신은 이야기해야 한다 / 당신의 야망과 / 꿈에 대해. /

Do not limit yourself / or be too self-conscious. / America is more individualistic, / while Korea / is more collectivist. /
자신을 제한하지 말라 / 또는 너무 남을 의식하지 말라. / 미국은 더 개인주의적이다 / 반면 한국은 / 더 집단주의적이다. /

In Korea, / people often care / about others' opinions / and go / where others are going. / That difference / also affects / work-life balance.
한국에서는 / 사람들은 종종 신경 쓴다 / 다른 사람들의 의견에 대해 / 그리고 간다 / 다른 사람들이 가는 곳으로. / 그 차이는 / 또한 영향을 준다 / 일과 삶의 균형에.

### ¶16

In Korea, / many people define / work-life balance / as working / in the office / and not working / outside the office. / The office becomes / a boundary. /
한국에서는 / 많은 사람들이 정의한다 / 워라밸을 / 일하는 것으로 / 사무실 안에서 / 그리고 일하지 않는 것으로 / 사무실 밖에서. / 사무실은 된다 / 경계가. /

미국에서는 / 적어도 내 경험상 / 사람들은 만들지 않는다 / 그런 종류의 경계를. / 만약 있다면 / 중요한 일이 / 사람들은 일할 수도 있다 / 사무실 밖에서. /

동시에 / 당신의 아이가 아프거나 / 당신이 아프다면 / 완전히 괜찮다 / 재택근무하는 것이 / 일찍 집에 가는 것이 / 또는 늦게 출근하는 것이. /

Where you are / during work hours / does not matter / as much. / If you are motivated, / people care less / about the number of hours. /
당신이 어디 있는지는 / 근무 시간 동안 / 중요하지 않다 / 그만큼. / 당신이 동기부여되어 있다면 / 사람들은 덜 신경 쓴다 / 시간 수에 대해. /

Compensation can also be / dramatically different. / In Korea, / working longer hours / and achieving more / does not necessarily translate into / much better compensation, / but in America / there can be / a big difference.
보상도 또한 될 수 있다 / 극적으로 다르게. / 한국에서는 / 더 오래 일하는 것과 / 더 많이 성취하는 것이 / 반드시 이어지지는 않는다 / 훨씬 더 좋은 보상으로 / 하지만 미국에서는 / 있을 수 있다 / 큰 차이가.

### ¶17

Many companies / are now talking about / going global. / Depending on the domain / you are aiming for, / the Korean market / may be big, / but often / it is not big enough. /

If you are going to suffer / as a founder, / you might as well suffer / for a bigger market / and a bigger opportunity. /
당신이 고생할 것이라면 / 창업자로서 / 차라리 고생하는 편이 낫다 / 더 큰 시장을 위해 / 그리고 더 큰 기회를 위해. /

In Korea, / if you start / with a small domain, / you often need / to add many features / to cover / a wider horizon. /
한국에서는 / 당신이 시작하면 / 작은 분야로 / 당신은 종종 필요하다 / 많은 기능을 추가할 필요가 / 커버하기 위해 / 더 넓은 범위를. /

In America, / you do not have to do that / because even a small segment / can be big enough. / That is / an important mindset change. /
미국에서는 / 당신은 그것을 할 필요가 없다 / 왜냐하면 작은 세그먼트조차 / 충분히 클 수 있기 때문이다. / 그것은 / 중요한 사고방식 변화이다. /

Because Korea has / many regulations, / founders may not think / outside the box. / When they move to America, / they may realize / that some regulations / do not exist.
한국에는 있기 때문에 / 많은 규제가 / 창업자들은 생각하지 못할 수 있다 / 틀 밖에서. / 그들이 미국으로 이동하면 / 그들은 깨달을 수 있다 / 어떤 규제들은 / 존재하지 않는다는 것을.

### ¶18

For now, / I will continue working / as an adjunct professor / at San Jose State. / Another potential project / is writing a novel / by turning the lessons / from my leadership book / into characters / and a plot. /

- **in terms of** [¶4](#¶4) — “~의 측면에서”라는 뜻으로 기준이나 관점을 말할 때 쓰는 표현.

- **get your message across** [¶8](#¶8) — “뜻을 전달하다”라는 실용적인 회화 표현.
- **as long as** [¶9](#¶9) — “~하는 한”이라는 조건 표현.
- **every other sentence** [¶10](#¶10) — “한 문장 걸러 한 문장마다”라는 빈도 표현.

- **go so far** [¶13](#¶13) — “어느 정도까지만 효과가 있다”라는 한계 표현.
